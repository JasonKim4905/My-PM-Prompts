# Figma 활용 프롬프트 (기획자용)

Figma에서 화면을 완성하기 위해 Figma Agent에 요청하는 프롬프트 입니다. 

---

## 1. 기존 [테이블 프레임]의 레이아웃에 [데이터 소스 프레임]의 데이터를 넣고 싶을때

**기본 프롬프트**
> [테이블 프레임]에 [데이터 소스 프레임]의 텍스트 데이터를 채워줘.
 - [테이블 프레임]의 레이아웃은 유지하고, 데이터에 맞게 불필요한 컬럼/행은 숨겨줘
 - 컬럼 너비는 텍스트가 1줄로 표시되도록 조정해줘
 - 텍스트가 아닌 컴포넌트가 들어있는 경우, 모듈러 라이브러리에서 가장 유사한 기능을 가지고 있는 컴포넌트를 적용해줘

> 여기서 [테이블 프레임]이나 [데이터 소스 프레임]은 피그마 레이어에서 해당 프레임명을 가져다가 쓰면 됨. 혹시 범용적인 프레임명이라고 하면 수정해서 특정되게 해주면 좋음

**예시**
> 세대차량_소유주_목록_아파트 프레임에 table-card_1의 텍스트 데이터를 채워줘.레이아웃 유지하면서 불필요한 컬럼/행 숨기고, 텍스트가 줄바꿈 없이 1줄로 나오도록 컬럼 너비 맞춰줘.단계·판정·상태 컬럼은 모듈러의 badge_m으로 적용해줘."

**팁**
- 여기서 [테이블 프레임]이나 [데이터 소스 프레임]은 피그마 레이어에서 해당 프레임명을 가져다가 쓰면 됨. 혹시 범용적인 프레임명이라고 하면 수정해서 특정되게 해주면 좋음
