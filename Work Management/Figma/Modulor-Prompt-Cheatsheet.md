# Modulor 화면 제작 — 프롬프트 치트시트 (기획자용)

이 프로젝트에서 Claude에게 화면을 요청하는 방법입니다. **제품명 + 웹/모바일 + 화면 구성** 세 가지만 말하면 됩니다.

---

## 1. 피그마 시안 요청 (기본 — 결과물이 피그마 파일에 남습니다)

**기본 패턴**
> [제품명] 테마로 [화면 설명] 화면을 피그마에 만들어줘.

**예시**
> HomeDot 테마로 입주민 목록 화면 만들어줘. 필터(단지·상태·검색)와 테이블, 페이지네이션이 필요해.

> RTB 테마로 잠재 매물 상세 화면 만들어줘. 기본 정보 카드와 동별 정보 탭이 있어야 해.

> RD 테마로 등기 신청 내역 화면. 상단에 기간 필터, 아래는 신청 목록 테이블.

> 모바일이야. HomeDot 테마로 공지사항 목록 화면 만들어줘.

**여러 화면 + 클릭 플로우(피그마 프로토타입)**
> RA 테마로 로그인 → 대시보드 → 매물 상세 3개 화면을 만들고, 클릭으로 이어지게 프로토타입 연결까지 해줘.

**PRD가 이미 있다면 — 노션 링크로 요청**
> 이 PRD 보고 HomeDot 테마로 화면 만들어줘. https://notion.so/…

> 이 기획안의 3.2 민원 접수 플로우 부분만 동작하는 프로토타입으로 만들어줘. https://notion.so/…

- 화면이 여러 개면 Claude가 목록을 먼저 정리해 확인받고 진행합니다. 특정 섹션만 원하면 지목하세요.
- 최초 1회 커넥터에서 Notion 연결 필요.

**팁**
- 제품을 안 쓰면 Modulor(기본)로 만들어집니다.
- 참고 화면 캡쳐를 붙이면 그 레이아웃을 우선합니다.
- 수정 요청은 대화로 이어서: "필터를 한 줄로 합쳐줘", "테이블에 상태 뱃지 추가해줘"

## 2. 동작하는 프로토타입 요청 (리뷰·시연용 — HTML)

입력, 조건 분기, 계산이 실제로 돌아가야 할 때 사용합니다.

**기본 패턴**
> [제품명] 테마로 동작하는 [화면 설명] 프로토타입 만들어줘. [동작 요구사항]

**예시**
> RD 테마로 동작하는 주소 검색 프로토타입 만들어줘. 주소를 입력하면 목록이 필터되고, 선택하면 상세 정보가 아래 펼쳐져야 해.

> HomeDot 테마로 관리비 계산 프로토타입. 면적과 단가를 입력하면 합계가 실시간 계산되고, 100만원 넘으면 경고가 떠야 해.

**주의**: 프로토타입은 시연용 "룩" 재현입니다. 방향이 확정되면 → *"이 화면 피그마로 정식 조립해줘"* 라고 요청해서 자산화하세요.

## 3. 자주 쓰는 후속 요청

> 같은 화면을 RTB 테마로 바꿔줘 (제품 전환)
> 빈 상태(검색 결과 없음) 버전도 추가해줘 (상태 변형)
> 이 캡쳐처럼 필터 영역을 바꿔줘 (캡쳐 첨부)
> 이 화면 피그마로 정식 조립해줘 (프로토타입 → 시안 자산화)
> 스크린샷으로 결과 보여줘 (확인)

## 요청 전 체크
☐ 제품명 (Modulor / HomeDot / RA / RD / RTB) ☐ 웹 or 모바일 ☐ 화면에 뭐가 들어가는지 한 문장 (또는 노션 PRD 링크)
