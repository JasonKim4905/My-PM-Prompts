# Claude로 화면 만들기 — 홈닷 기획자 온보딩 가이드

> Modulor 디자인 시스템으로 화면 시안과 프로토타입을 직접 만드는 방법입니다. 디자인 툴을 몰라도 됩니다 — **말로 요청하면 화면이 나옵니다.**
> ⚠️ **Pro 계정과 엔터프라이즈 계정은 세팅 방법이 다릅니다.** 본인 계정에 맞는 섹션을 따라주세요. (요청하는 방법 자체는 동일합니다.)

---

## 0. 무엇을 할 수 있나요

| 트랙 | 결과물 | 언제 쓰나 |
|---|---|---|
| **① 피그마 시안** (기본) | 피그마 파일에 실제 디자인 시스템 컴포넌트로 조립된 화면 | 요구사항을 화면으로 구체화할 때, 디자이너에게 전달할 때 |
| **② 동작 프로토타입** | 브라우저에서 열리는 HTML — 입력·클릭·계산이 실제로 동작 | 기획 리뷰, 이해관계자 시연, 유저 플로우 검증 |

두 트랙 모두 홈닷의 실제 디자인 시스템(컬러·컴포넌트·GNB·사이드메뉴·로고)이 자동 적용됩니다.

## 1. Pro 계정 — 처음 세팅하기 (10분, 최초 1회)

개인 계정에서는 공유 프로젝트를 쓸 수 없어서, **각자 자기 프로젝트를 하나 만들어야** 합니다. 아래를 순서대로 따라 하세요.

**준비물**: 관리자가 공유한 세팅 파일 3개 — `Modulor-Project-Instructions.md` · `Modulor-Claude-Master-Guide.md` · `modulor.css`. 없다면 관리자에게 요청하세요.

1. **claude.ai 접속 → 로그인** (Pro 구독 계정)
2. 왼쪽 사이드바에서 **"프로젝트(Projects)" 클릭 → "+ 새 프로젝트"** 클릭
3. 프로젝트 이름을 **`Modulor-디자인시스템`** 으로 입력하고 생성
4. **지침 넣기**: `Modulor-Project-Instructions.md` 파일을 메모장 등으로 열어 **내용 전체 복사** → 프로젝트 화면 우측 **"지침" 옆 + 클릭** → 붙여넣기 → 저장 (⚠️ 지침은 파일 업로드가 아니라 텍스트 붙여넣기입니다)
5. **파일 넣기**: 그 아래 **"파일" 옆 + 클릭** → `Modulor-Claude-Master-Guide.md`와 `modulor.css` **두 파일을 업로드** (드래그해도 됩니다)
6. **커넥터 연결**: 대화 입력창의 **+ 버튼 → 커넥터** → 목록에서 **Figma**를 찾아 "연결" 클릭 → 피그마 계정으로 로그인해 허용. **Notion**도 같은 방법으로 연결 (PRD 링크 기능용)
7. 끝! 그 프로젝트 안에서 **새 대화를 열고** 아래 3장의 공식대로 요청하세요.

> 💡 **주의**: 반드시 이 프로젝트 **안에서** 대화를 시작해야 디자인 시스템이 적용됩니다. 일반 채팅에서는 적용되지 않아요.
> 💡 관리자가 "세팅 파일이 업데이트됐다"고 공지하면, 프로젝트의 기존 파일을 지우고 새 파일로 다시 업로드해주세요. (개인 프로젝트라 자동으로 갱신되지 않습니다.)

## 2. 엔터프라이즈 계정 (2분)

엔터프라이즈 계정은 세팅이 훨씬 간단합니다:

1. claude.ai에서 회사 계정으로 로그인 → 공유 프로젝트 **「Modulor-디자인시스템」에 들어가기만 하면 됩니다.** 지침·파일이 이미 세팅되어 있고, 관리자가 갱신하면 자동 반영됩니다.
2. **커넥터(Figma·Notion)만 본인 계정으로 1회 연결** — 방법은 위 1장의 6번과 동일.
3. 개인 계정에 만들었던 프로젝트는 더 이상 안 써도 됩니다. (기존 대화 기록이 필요하면 개인 계정에서 열람 가능)

## 3. 요청 공식 (계정 종류 무관 공통)

> **HomeDot 테마로 + [웹/모바일] + [화면에 뭐가 들어가는지 한 문장]**

이게 전부입니다. 동작이 필요하면 앞에 **"동작하는"** 을 붙이세요.

### 예시 — 피그마 시안
> HomeDot 테마로 입주민 민원 관리 화면을 피그마에 만들어줘. 상단에 필터(단지·처리 상태·검색), 아래는 민원 목록 테이블(접수번호·접수일·민원 내용·담당자·상태 뱃지), 맨 아래 페이지네이션.

> HomeDot 테마로 관리비 부과 현황 화면. 월 선택 필터와 단지별 부과 요약 카드, 세대별 상세 테이블이 필요해.

### 예시 — 동작 프로토타입
> HomeDot 테마로 동작하는 관리비 계산 프로토타입 만들어줘. 면적과 단가를 입력하면 합계가 실시간 계산되고, 100만원을 넘으면 경고가 떠야 해.

### 예시 — 여러 화면 연결 (클릭 플로우)
> HomeDot 테마로 민원 목록 → 민원 상세 → 담당자 배정 모달, 3단계 화면을 만들고 클릭으로 이어지게 프로토타입 연결까지 해줘.

### PRD가 이미 있다면 — 노션 링크로 요청 ⭐
요구사항을 다시 타이핑할 필요 없습니다. **노션 PRD 링크를 붙이면 Claude가 문서를 직접 읽고** 화면을 만듭니다.

> 이 PRD 보고 HomeDot 테마로 화면 만들어줘. https://notion.so/…

> 이 기획안의 3.2 민원 접수 플로우 부분만 동작하는 프로토타입으로 만들어줘. https://notion.so/…

- PRD에 화면이 여러 개면 Claude가 **화면 목록을 먼저 정리해 확인**받은 뒤 만듭니다. 특정 화면만 원하면 섹션을 지목하세요.
- PRD에 **화면 구성(필터·컬럼·버튼)**, **상태(빈 상태·에러)**, **참고 캡쳐**가 있을수록 결과가 정확해집니다. 미확정 문구는 Claude가 실무 카피로 채웁니다.

## 4. 결과 받고 수정하기

- **피그마 시안**: 완성되면 해당 프레임으로 가는 피그마 링크를 줍니다.
- **프로토타입**: HTML 파일을 다운로드해 브라우저로 열면 바로 동작합니다.
- **수정은 대화로**: "필터를 한 줄로 합쳐줘", "테이블에 경과일 컬럼 추가해줘" — 이어서 말하면 됩니다.
- **참고 화면 캡쳐를 붙이면** 그 레이아웃을 우선해서 만듭니다.
- **결과가 실제와 다르면** 캡쳐와 함께 알려주고, 관리자에게도 공유해주세요. 시스템 규칙에 반영됩니다.

## 5. Claude Design과는 뭐가 다른가요?

회사에는 Claude Design에도 Modulor 디자인 시스템이 구축되어 있어서 헷갈릴 수 있습니다. 역할이 다릅니다:

> **이 파이프라인** = 우리 컴포넌트로 "정확한 화면"을 빠르게 찍어내는 **공장**
> **Claude Design** = 아이디어를 만져볼 수 있게 만드는 **실험실**

| 비교 | 이 파이프라인 | Claude Design |
|---|---|---|
| 결과물 | 피그마 시안(실컴포넌트) + HTML 프로토타입 | 동작하는 HTML 프로토타입 |
| 디자인 시스템 정확도 | **실제 컴포넌트·토큰 그대로** — 어긋날 수 없음 | 시스템을 참조해 재현 — 미세하게 다를 수 있음 |
| 디자이너에게 전달 | **피그마 시안을 그대로 이어서 작업 가능** | 피그마로 다시 그려야 함 |
| 인터랙션 | 클릭 플로우 + 동작 프로토타입 가능 | 고밀도 인터랙션·복잡한 로직에 강함 |
| 속도·사용량 | 가볍고 빠름 | 무거움 (사용량 소모 큼) |
| 강점 | 시스템 **안에 있는 것**의 조합 | 시스템에 **없는 것**의 탐색·발산 |

**언제 무엇을 쓰나** — 기본은 이 파이프라인입니다. 일상적인 화면 요청(목록·상세·폼·대시보드 등 기존 컴포넌트 조합)은 전부 여기서 처리하세요. Claude Design은 **완전히 새로운 기능의 컨셉을 발산하거나, 기존 컴포넌트로 표현이 안 되는 고밀도 인터랙션을 실험할 때만** 선택적으로 씁니다.

**둘을 잇는 법**: Claude Design에서 컨셉이 확정되면, 그 화면 캡쳐를 이 파이프라인에 붙여서 *"이 캡쳐대로 HomeDot 테마로 피그마에 정식 조립해줘"* 라고 요청하세요. 발산은 Claude Design이, 확정과 자산화는 피그마가 맡는 분업입니다.

## 6. 자주 묻는 질문

**Q. 프로젝트 안에서 대화했는데 디자인 시스템이 적용 안 된 것 같아요.** → ①그 대화가 정말 프로젝트 안에서 열렸는지(화면 상단에 프로젝트 이름 표시) ②지침·파일이 모두 들어갔는지 ③피그마 작업이면 Figma 커넥터가 연결됐는지 확인하세요. 그래도 안 되면 관리자에게 문의.

**Q. 제품명을 안 쓰면?** → Modulor(사내 기본 테마)로 만들어집니다. 홈닷 화면이면 꼭 "HomeDot 테마로"를 붙이세요.

**Q. 프로토타입을 그대로 개발에 넘겨도 되나요?** → 아니요. 프로토타입은 리뷰·시연용 "모양 재현"입니다. 방향이 확정되면 "이 화면 피그마로 정식 조립해줘"라고 요청해 피그마 시안으로 자산화한 뒤 전달하세요.

**Q. 어느 피그마 파일에 만들어지나요?** → 전용 작업 파일(MODULOR_PLAYGROUND)에 만들어집니다. 원본 디자인 시스템 파일은 건드리지 않습니다.

**Q. 개인 계정 사용량 제한에 걸리면?** → Pro 계정은 개인 사용량 한도가 있어 대량 작업 시 잠시 대기가 필요할 수 있습니다. 엔터프라이즈 계정에서는 여유가 커집니다.

**Q. 요청 하나에 얼마나 걸리나요?** → 화면 1장 기준 피그마 시안 몇 분, 프로토타입 1~2분 내외입니다.
