# HTML 프로토타입 프롬프트

## 기본 HTML 프로토타입 생성
다음 기능의 HTML 프로토타입을 HomeDot 스타일로 만들어줘. 
이 프로토타입의 최종 목표는 프로토타입 개발 내용을 개발자에게 전달하기 위한 피그마 작성하는데 있음을 명심해.

GNB, LNB는 피그마(https://www.figma.com/design/tECnIyLJQP1jAh6yhTi26V/%ED%99%88%EB%8B%B7-%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C?node-id=1562-40054&t=BIxVwNWOJxyl1SAU-1) 스타일 반영

실제 동작하는 인터랙션 포함 (클릭, 입력, 검색 등)

모바일/데스크탑 기본 사이즈는 [모바일 사이즈/데스크탑 사이즈]
더미 데이터로 실제처럼 보이게

토큰만 사용, hex/px 금지(modulor.css의 CSS 변수·.mdl-* 클래스만 사용)

CORE에 실재하는 컴포넌트만 사용 — 새 UI가 필요하면 처음부터 "대체/신규 필요"로 표시(임의로 도형화 금지)

컴포넌트 계약(주석) — 각 요소에 data-mdl="Button/Primary/Large"처럼 컴포넌트·variant·프로퍼티·바인딩 토큰을 달기

웹/모바일 컴포넌트 분리 — 동명 컴포넌트는 _Mobile 명시.

"피그마 우선" 검증 포함 — .mdl-*는 룩 재현일 뿐이라, 최종은 게시 라이브러리 실물과 대조.
